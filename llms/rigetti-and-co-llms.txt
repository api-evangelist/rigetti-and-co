# Rigetti & Co — Quantum Cloud Services (QCS)

> Rigetti Computing builds superconducting quantum processors and delivers access to them over Quantum Cloud Services (QCS). The QCS HTTP API is a REST/RPC interface (Google AIP-aligned) for discovering quantum processors and their instruction set architectures, reserving execution time, creating execution engagements/endpoints, and managing accounts and billing. Program build/execution is done with the pyQuil / qcs-sdk Python and Rust SDKs; low-latency job execution and translation run over a companion gRPC surface. Generated by the API Evangelist enrichment pipeline from the provider's published OpenAPI, gRPC protos, packages, and docs.

## APIs
- [Rigetti QCS API (OpenAPI 3.0.2)](https://api.qcs.rigetti.com): 52 operations across quantum processors, endpoints, engagements, reservations, client applications, authentication, and account/billing. Auth: OAuth2 (Okta) bearer JWT.
